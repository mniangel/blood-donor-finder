Blood Donor Finder

A web-based prototype designed to help users identify potential blood donors through blood group compatibility and preliminary donor eligibility checks.

Features

- Donor registration interface
- Blood request system
- Blood group compatibility matching
- Preliminary donor eligibility checks
- Dashboard and simulated alerts

Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

Project Status

This is a frontend prototype that uses simulated data. Backend, database, and live API integrations are planned for future development.
